# backend — שליחת הודעות WhatsApp דרך Green API

שרת מקומי קטן שרץ **רק על המחשב שלך**. הוא לא מתפרסם לשום מקום, לא מחובר
ל-GitHub Pages ולא ל-Artifact של JACRICE — כי שם (ה-CSP של הדף) חוסם קריאות
API החוצה, וגם כי הריפו הזה ציבורי ואסור שיהיו בו מפתחות אמיתיים. המפתחות
שלך יישארו אך ורק בקובץ `.env` המקומי, שלא נדחף ל-git.

## הרצה ראשונה

1. **Node.js 18+** צריך להיות מותקן (יש בו `fetch` מובנה — אין תלויות
   חיצוניות בפרויקט הזה בכלל).
2. במסוף ה-Green API (console.green-api.com): צרו Instance, וקחו משם שלושה
   ערכים — **idInstance**, **apiTokenInstance**, וה-**apiUrl** הספציפי
   שמוצג לכם (לא תמיד `api.green-api.com` — לאינסטנסים חדשים יש שרתים
   ייעודיים).
3. חברו את המספר לאינסטנס (QR או קוד טלפון) לפי ההוראות בקונסולה.
4. בתיקייה הזו:
   ```bash
   cp .env.example .env
   ```
   ופתחו את `.env` ומלאו את שלושת הערכים.
5. הרצה:
   ```bash
   node server.js
   ```

## שימוש

**שליחה חד-פעמית מה-CLI** (בלי להריץ שרת):
```bash
node send.js 0501234567 "היי, זו הודעת בדיקה מ-JACRICE"
```

**שרת מקומי** (`node server.js`) — מאזין על `http://localhost:3001`:
```bash
curl -X POST http://localhost:3001/send \
  -H "Content-Type: application/json" \
  -d '{"phone":"0501234567","message":"היי, זו הודעת בדיקה"}'
```
מספרי טלפון מתקבלים בפורמט ישראלי מקומי (`050-...`) ומומרים אוטומטית
ל-`972...@c.us`. אם תרצו לשרת גם לקוחות מחוץ לישראל, תצטרכו להתאים את
`normalizePhoneToChatId` ב-`green-api.js`.

## לפני שמתחילים לשלוח באמת — סיכון חסימה

Green API הוא אינטגרציה **לא רשמית** (מדמה מכשיר מקושר, לא ה-WhatsApp
Business Platform הרשמי של Meta):

- למספר **חדש** הסיכון הכי גבוה הוא ב-10 הימים הראשונים. חכו 24 שעות אחרי
  רישום המספר לפני שמחברים אותו, ואל תשלחו ליותר מ-~20 אנשי קשר חדשים ביום
  בהתחלה.
- **מומלץ בחום לא לחבר את המספר האישי/הראשי של סיגל** — מספר ייעודי נפרד
  לאוטומציה, כך שאם יש חסימה זה לא פוגע בקו התקשורת המרכזי שלה.

## מה זה *לא* עושה (עדיין)

- לא מקבל הודעות נכנסות (webhook) — זה דורש כתובת ציבורית שהמחשב שלכם לא
  חושף כברירת מחדל. אפשר להוסיף בהמשך עם כלי כמו ngrok, אם תרצו.
- לא מחובר לדאשבורד JACRICE החי (ה-Artifact) — זה כלי עצמאי בינתיים. חיבור
  אמיתי בין השניים ידרוש backend ציבורי אמיתי, לא תיקייה מקומית.
